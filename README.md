# Hobbit Vault

My Magic: The Gathering collection from *The Hobbit* set: every card I own, where each copy lives
(deck boxes, spare piles, box 2, box 3), a swipe-through deck browser, card search and a deck builder.

- **Decks:** swipe between the five decks, open one and swipe through its cards. The bar at the bottom is the
  mana curve and doubles as a scrubber. Foils and special versions get a holographic layer that follows the
  pointer (or the phone's tilt).
- **Cards:** search German or English names, types and rules; filter by colour, place, foils.
- **Boxes:** what is in box 2, box 3 and each deck box.
- **Build:** new decks or copies of existing ones, saved in the browser; copy the list in Sorted's import format.

## Data
`src/data/*.json` is generated by `scripts/build_data.py` from the Sorted export and my deck lists.
`scripts/fetch-scryfall.mjs` runs before every build and pulls German names, rules text and image links from
Scryfall. If Scryfall can't be reached the app falls back to Scryfall's image API links.

## Run
```
npm install
npm run dev
```
Deploys on Vercel as a plain Vite app.
